# Roadmap

These phases describe direction. A phase listed here is not a feature you can use until it ships.

## Phase 1 — Open-source release

Repository docs, license, and a public-ready README. In progress.

## Phase 2 — Self-hosting

`DEPLOYMENT_MODE=self-hosted` unlocks the core app. Still required: your own Supabase project and Postgres. A Compose setup that includes authentication is not done.

## Phase 3 — Paid Alavo Cloud

New hosted accounts require a paid plan. Existing customers, including lifetime purchases, keep their access. No permanent free Cloud tier for new accounts. Not switched on yet.

## Phase 4 — AI Coach

Today's coaching is rule-based from the user's own stats. A model-backed coach, with explicit consent before any journal text is sent, comes later. Cloud Pro should not be advertised until this exists.

## Phase 5 — Business accounts

Organizations, admin tools, and custom branding. The current Team/Family group is a small shared space, not this product.

## Phase 6 — Ecosystem

Themes, templates, and integrations. Not started. Do not build a marketplace yet.
