# License

Alavo is released under the **GNU Affero General Public License v3.0** (`AGPL-3.0-only`).

This is a product decision, not legal advice. Have a lawyer review it before a public release if that matters for you.

## Why AGPL-3.0

The core habit tracker should stay genuinely open source, including when someone runs a modified copy as a network service. AGPL-3.0 requires those modifications to be shared with the users of that service. That matches the goal of discouraging closed hosted forks that change Alavo and do not publish the changes.

Self-hosting, modifying, and contributing remain allowed. Running Alavo for yourself is allowed. Offering a modified version to other people over a network means you share the corresponding source.

## Dependencies

The application depends on permissive libraries, including Next.js (MIT), React (MIT), Prisma (Apache-2.0), and Supabase client libraries (MIT). Those licenses still apply to those packages. AGPL applies to Alavo's own code. No copyleft dependency was found that would block AGPL for the application source.

If a future dependency is incompatible with AGPL, document it here and reconsider the license before adding that dependency.

## What this does not do

The license does not create a paid license server, a phone-home check, or a feature lock for self-hosting. Cloud billing is a separate hosted service, not a copyright restriction on the software.
